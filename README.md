# Kladovki

Storage-room (кладовка) rentals for residential complexes in Kazakhstan. Residents book and pay with Kaspi; the building's ОСИ manages storage rooms, tariffs, debts and requests.

- **Backend**: Go + gin + PostgreSQL (`backend/`)
- **Frontend**: Angular + Capacitor Android (`frontend/`)
- **Hosting**: Render (app) + Supabase (DB)

📚 **Documentation: [docs/](docs/README.md)**. It covers the architecture, API, data model, payments, notifications, security, and how to run and deploy.

Quick start: see [docs/operations.md](docs/operations.md#run-locally).
